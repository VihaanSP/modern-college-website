# The Academic Standard - Conceptual Redesign

A premium, interactive conceptual redesign for a university portal, built with **Vite, React, and Framer Motion**. 

This portfolio piece visualizes what a university portal looks like when engineered with an uncompromising focus on academics, research, and global opportunities (such as GSoC, ICPC, and Competitive Programming) rather than traditional marketing.

## 🚀 Features

- **Fluid Framer Motion Animations:** Spring physics, scroll-based transformations, and interactive hover states.
- **Apple VisionOS-Style Cursor:** A high-end liquid glass cursor with `backdrop-filter` and `mix-blend-mode: difference` for perfect X-Ray text readability.
- **Interactive Mentor Roadmaps:** Dynamic, beautifully animated views for deep-dive roadmaps into elite programs (GSoC, LFX Mentorship, ICPC World Finals, etc.).
- **Bento Grid Architecture:** A modern, mobile-responsive bento grid system for highlighting global research opportunities.
- **Horizontal Scroll Curriculum:** A deterministic scroll section highlighting the engineering roadmap with massive mathematical background watermarks.

## 🛠️ Tech Stack

- **React 18**
- **Vite** (Lightning-fast HMR)
- **Framer Motion** (Production-ready animations)
- **Vanilla CSS** (Custom high-performance styling without heavy frameworks)

## 📦 Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/VihaanSP/modern-college-website.git
   ```
2. **Navigate into the project:**
   ```bash
   cd modern-college-website
   ```
3. **Install dependencies:**
   ```bash
   npm install
   ```
4. **Start the development server:**
   ```bash
   npm run dev
   ```
5. **Open in Browser:**
   Visit `http://localhost:5173`

## 🎨 Design Philosophy

*“Fund Academics, Not Ads.”*

The design philosophy behind this project is to strip away corporate university marketing and replace it with raw, elite academic aesthetics. Massive typographic elements, mathematical watermarks (like `O(N LOG N)` and `∇F(X)`), and a brutalist dark mode theme serve to emulate the high-end culture of elite engineering and software development.
